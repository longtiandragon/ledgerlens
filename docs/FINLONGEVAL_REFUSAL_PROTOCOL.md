# FinLongEval 公开样例：拒答阈值外部迁移协议

2026-10-23。在运行排名和查看本批答案/问题类型分布之前固定。已在准备阶段读取公开文件 schema、行数与文档路由，不把这称为秘密测试集。

使用作者仓库版本 `b2cb7b11d850a17381f82ac7f8950970e7b9b955` 的 `data/sample_data.jsonl` 全部 80 条。它是公开样例子集，不是作者完整 347 题。全部相关 PDF 保留原字节和 Git blob/SHA-256；未提供或无法匹配的 PDF 产生显式失败，不筛除对应问题。只做规范化文件名匹配（NFKC、空白、引号、下划线及连接号），不用答案找文档。

目标是检验现有排序分数阈值对外部中文金融文档的迁移能力，**不是生产 API、制度适用性或完整问答正确率**。每题只检索作者指定的那份文档，来源范围由数据集直接给定；这是有利的已知文档条件，不能外推跨文档发现能力。

原 PDF 由已安装 pdfplumber 逐页抽取文字，不做 OCR、不修答案。空页面保留计数。沿用 OfflineBGE 的 480-token 窗口、400 stride、query prefix、冻结本地模型与依赖；关键词与 BGE 使用相同窗口。只用本地 NumPy 精确余弦，不声称是 pgvector 实跑。只把文档正文、问题和中性路由送入评分；问题类型、参考答案不进入排名。

冻结阈值为此前开发集选定的关键词 `0.2857142857142857`、BGE `0.5847992897033691`，不在新数据重选。另报告无阈值原排序作为描述性对照。得分至少达到阈值才接纳。所有 80 条的两个方法预测保存后，才打开原文件评分。

作者 `question_type` 为“陷阱问题”的题目作为拒答目标；其他题目作为应保留的回答候选。这一代理标签只测接纳/拒绝，不测返回片段是否足以支持正确答案。报告陷阱误接纳数/拒绝数、其他题目保留数/拒绝数、失败数，不能把失败当正确拒答。若无陷阱或标签不符合预期则报告不可评分，不发明真值。没有事后产品达标阈值，不把高接纳率称为正确检索率。

不调用付费模型、不自动生成答案、不写入原账簿。题目和文档公开已久，预训练污染未知；领域也不同于中文会计制度检索。结果不能与 v4 原因分类宏 F1 相加或互相替代。
