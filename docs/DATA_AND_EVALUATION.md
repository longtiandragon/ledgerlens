# 数据与验证

## 来源分类

财政部规则及公开案例用于政策/案例一致性；巨潮与交易所报告用于文档和勾稽组件；BPI2019用于采购流程适配；FinQA用于财报数字推理；合成账套用于受控端到端任务。某数据集能验证的层次不能扩展解释成真实业务原因准确率。

`data-sources.json`是来源登记，目录页面不是已采集案例、数据集主页不是已取得完整数据集。`scripts/collect_sources.py`按显式清单下载，限制HTTPS白名单、大小和跳转，保存URL/哈希/解析版本/时间与失败原因。原始资料不进入Git。运行结果在 `runtime/public-sources/acquisition-report.json`。

知识索引只接纳独立登记的政策类型，排除官方答案、案例目录与组件评测材料。新版加载器重新核对原件字节、解析内容和全部片段，拒绝错标类型、路径替换及已测试的内容篡改；实际两个归档来源13片段已重建并启用，105项独立检查通过。旧未绑定参考不进入新的生产模型任务，旧底稿保留；不能抵抗同时重写可信登记、原件及全部摘要的本机攻击者，也不是来源真实性或现行效力认证。有效期结束尚未支持，非空声明拒绝；未知起始日期带unverified状态。见[来源绑定](REFERENCE_PROVENANCE.md)。已取得32条官方政策问答，其中六条实现独立有限规则，30个手写结构化开发投影通过一致性验收；其余26条未实现。10家公司各3年报告已取得并核查文档身份，金额和业务结论验证按组件分别记录。不能把自建参考例重新标成官方例，也不能把已下载的数据直接当成模型评测成绩。

## 合成账套

程序先生成业务事件，再派生账簿/单据，然后注入故障；金额与标签不由LLM自由生成。`observed/`、`on_demand/`、`truth/`分开。正常、重复、冲突、缺失、跨期、复合异常均包含。48个拓扑/故障配置×10变体=480任务，CAS/SCAS各240；按族拆分30/8/10。同族全部变体保持在同一拆分。

现有family会共享故障类型，不应把测试成绩解释成未知领域泛化。封存评测不能在每轮调提示词时查看答案；本地开发隔离不防恶意管理员。正式封存建议由不同评测账户控制原始truth。

## 独立答案

`benchmarks/oracle.py`使用独立Fraction/整数实现，未调用生产核算函数。`reference_cases.py`包含30个人工编写的独立算术/约束案例，明确不是财政部官方案例。Hypothesis比较确定性核算与独立参考。第三方ERP/Beancount差分必须对齐政策、符号和计价方法，不把另一软件输出自动当真理。

已执行的`benchmarks/beancount_differential.py`分别使用独立手写Beancount文本与本平台分录，第三方loader、validation、balance_by_account提供参考；生产计算只产生实际值。9/9中8个比较精确余额、1个验证一分不平衡拒绝，日期截止为排他边界，各月采用独立期初结转。还包含“借贷平衡但科目错误”的边界账例，两侧算术检查都接受它，明确说明本参考无法发现业务处理错误。

首次差分8/9的生产表示错误及修正原因保存在本地，没有修改第三方文本或金额答案。Beancount仅是可选评测工具，不进入应用运行依赖；[安装及复现](BEANCOUNT_DIFFERENTIAL.md)需显式安装。真实ERPNext联调和更复杂政策／库存计价差分仍未完成。

## 指标边界

规则实验统计命中规则集合、每规则TP/FP/FN、Macro规则标签F1、执行失败、按制度分项和正常案例误报。生成器覆盖的标签与检测器高度一致，因此高分只是受控回归，不能宣传为任意账套准确率。

Agent实验使用中性任务和可观察记录，不将故障标签传入模型；单Agent、多Agent、主动补证共享工具权限和预算。评分模型建议而不是受程序保护的fact_status。三次重复、所有失败、耗时与Token均保留。无Key不得产生模型成绩，Mock输出仅用于测试传输和评分路径。

结构化claim的`assessment=finding`才进入异常标签，`normal`表示检查正常，`insufficient`表示无法检查该条件，`unsupported`表示范围外。不能把“该凭证借贷平衡”因引用VOUCHER_BALANCE就计作异常，也不按自由文本关键词决定评分。所有方法共享标签集合；全目录F1和本次覆盖标签F1分别报告。区间按场景族聚类Bootstrap，重复运行不当成独立行业样本。

CLI显式`--env-file .env`可读取本地配置，进程环境变量优先，不自动读文件或输出密钥。模型尝试及用量事件保存`current_sample`，中断保留未完成状态。同一服务返回401／402／403后，本批次后续模型样本标为未执行，规则组继续运行。

网关已保留提供方实际返回的逐请求prompt／completion／total、缓存命中／未命中及reasoning用量，缺失为null，明确0保留0。benchmark-v5记录逻辑请求、物理尝试、发送前拒绝和实际用量；失败及无法评分样本仍进入成本汇总。`benchmarks/costs.py`以2026-10-08核验的[官方USD价格](https://api-docs.deepseek.com/quick_start/pricing/)离线计算已知用量峰谷区间，未知尝试单列，不推算RMB、余额或实际账单。缺少缓存分项、未知模型或矛盾用量不强行赋值。15项独立费用测试通过；质量／成本增益仍需公平重复实验支持。

消融包括去反证、去主动选择、去时间视图、去模型计算复核；涉及未来资料只对显式合成比较开放。系统并不执行正式调整，因此不能把去模型数值复核命名为已完成全面会计模拟消融。

## 复现

```powershell
.venv\Scripts\python.exe -m datasets.generate --output .local/datasets
.venv\Scripts\python.exe -m benchmarks.evaluate
.venv\Scripts\python.exe -m benchmarks.run_agents --help
.venv\Scripts\python.exe -m benchmarks.run_agents --env-file .env --max-cases 4 --repeat 1 --max-paid-requests 96 --report .local/reports/agent-pilot.json
```

默认规则基线不调用API。付费模型实验先配置本地环境Key，限制任务数、重复数和全局调用预算。结果保留模型响应名称、日期、提示词和工具指纹；别名更新可能影响以后复现。

2026-10-08首轮实际四组试跑使用v4：4族×1次，共16样本、47次已记录API尝试；规则4/4、单Agent2/4、多Agent与主动0/4完成，包含预算与HTTP402失败。后续v8／v9分别停在13／5个已结束样本，保留中断及用量下界。v15完成2族×3次×4方法共24个样本、107次API尝试；规则6/6、单Agent6/6、多Agent0/6、主动3/6完成。完整重复要求已达到，但只有两个独立场景族和一个观测异常标签，不能当成正式泛化评测或根因准确率。全指标与失败见[试跑报告](AGENT_PILOT_V15.md)。

真实产品v10主动调查通过（6次请求、90292 Token、8次工具），固定快照、12条引用定位、导出及原账簿未改写验收通过；v10／v11／v13固定多Agent仍预算失败，分别记录5／9／8次请求。v13前两角色完成交接，政策角色终止，不能只统计前两角色而宣称全流程成功。不同版本单次Token差异不能证明主动机制或多Agent收益。

v16使用显式政策检索、定义无损去重、来源关系展开及计划修复契约；v17的中性任务初始化、规则编号约束与无损传输通过回归，但其完整24样本仍有7次模型失败；固定多Agent产品验收预算失败。v18同预算职责交接试跑因预算及HTTP402结束；当前v19按角色读取完整快照依据、保留全查询索引和程序观察，最新工程检查见交付状态，尚无v19真实模型验收；未执行的模型行明确单列，不算实际运行。v14固定多Agent预算终止（9次请求、140892 Token、30次工具）；v15产品主动调查计划校验失败（5次、85211 Token、5次工具），记录保留。v16真实主动产品流程通过（6次、101950 Token、4次工具），13条不同引用可定位、原账簿不变；v16同版本24样本全部运行，114次API尝试；固定多Agent0/6、主动5/6完成，主动规则集合仅1/6完全匹配。中性任务初始化缺陷及全部失败见 [v16报告](AGENT_PILOT_V16.md)。程序选择器按“可区分解释对数／整数成本”查询，模型不能指定成本，预期分区不是概率或事实；补证请求不会取得快照外资料。流程通过及Mock回归不能代替根因分类、机制消融和真实业务验证。

公开聚合`live-model-validation-summary.json`保留原协议／v4摘要及后续`trial_history`／`batch_history`，可以运行`.venv\Scripts\python.exe scripts/summarize_live_validation.py`刷新，不调用模型。具体失败和版本边界见[交付状态](STATUS.md)。
