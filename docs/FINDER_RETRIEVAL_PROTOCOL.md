# FinDER 固定参考池检索增益实验 v1

2026-10-24，预测前协议。研究范围：外部英文财报的已标注参考片段池检索；不是原始整份年报检索、中文政策适用性、可靠拒答、原因调查或自动入账。不能用本实验通过替换原因调查 F1、决定性补证率等原验收门槛。

来源为 Choi 等作者的 [FinDER](https://huggingface.co/datasets/Linq-AI-Research/FinDER)，固定版本 c4c1b6454aef7f0bb1c37235c7f52ce644642da0。数据许可证 CC-BY-NC-4.0，仅用于本次非商业学生研究，不将原始财报片段或答案加入项目 Apache-2.0 发布包。公开数据可能进入预训练，不能证明无污染。

全部 5703 题都参与，无开发调参、无按成绩筛选。准备程序只读 `_id`、`text`、`references` 三列，不读 answer。将所有原样参考片段按 SHA-256 去重并排序形成 5832 个候选父片段；查询仅含编号和问题，题目与参考片段的对应关系独立保存。候选池由标注参考组成，缺少未标注年报干扰片段，因此它是明确缩小范围的派生实验，不是官方全语料成绩。先保存所有方法全部预测，才打开对应关系评分。

所有方法使用现有 OfflineBGE 的 480-token 窗口、400-token 步长；相同文本、父片段聚合、候选数和返回数。冻结项目 BGE-small-zh-v1.5、中文 query prefix、CPU、模型哈希和版本，不因英文任务更换模型或调提示。按父片段最高窗口分数排序，分数相同按父片段 SHA-256 升序，返回 6 个不同父片段。

比较方法：项目关键词覆盖率；BM25（k1=1.2,b=0.75，英文小写字母数字词，无停用词删除）；TF-IDF 余弦（相同词法，平滑 IDF、L2 归一）；现有 BGE 余弦；固定 RRF 混合（BM25 与 BGE 的完整父片段排序，常数 60）。额外确定性方法用于避免只击败弱关键词。RRF 是新研究组件，尚未进入产品。

主指标是每题已标注父片段 recall@6 的全题均值，次指标 hit@1、hit@6、MRR@6；无完整相关性标注，不将未标注候选宣称为一定不相关。增益与三个确定性方法中本批主指标最强者比较。每个 AI 方法必须同时达到：平均增益 >=0.05、配对重采样区间下界 >0、无执行失败，才支持此有限假设。为两种 AI 候选作 Bonferroni 调整，各用 97.5% 双侧区间（分位点 0.0125/0.9875）。用共享任一真值父片段的题目连通分量聚类重采样 2000 次，种子 20261024；每次重采样重新选最强确定性比较器。该聚类不能完全控制公司或文档模板相关性，区间不代表真实企业总体。

任何失败、预算终止均保留。失败预测按空列表记零并阻止支持结论；失败不单独重跑。运行目录拒绝覆盖，编码缓存和进度保留。意外中断后须另写接续协议，不能覆盖运行历史。不调用付费服务，不使用 v5 预算，不修改生产规则和历史实验。
