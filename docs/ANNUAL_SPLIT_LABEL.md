# 年报总计标签跨物理单元格的有界支持

本次只增加一种可核验布局：同一表格内的两个相邻标签单元格，金额单元格合并跨两段标签的完整高度。没有使用模型、OCR、网络或 `资产－负债` 推算权益；缺币种、合并与公司组合列头等格式仍拒绝。

## 识别条件与来源字段

- 只接受六个物理列中第 1 列（从 0 起）的两个相邻标签片段；连接后的标签必须精确命中全体权益总计的既有别名。
- 两个片段的 x 范围一致、y 边界相接。两个金额、附注及左右空白边单元格必须覆盖整个标签高度。
- 左右空白边宽度不超过 8 PDF 点，几何边界相接；附注为空。后一个物理行不得带其他文字或物理金额单元格。
- 当前、上期金额仍按显式列头及几何匹配确定；每个标签片段还须出现在自身 y 范围内的原文行中。
- 金额缺失继续明确失败；不从另一年度、归母行或勾稽公式补值。

普通观察字段保持原含义。跨行观察额外提供 `table_rows`（两个一基行号）与 `label_fragments`（每片段的行号、零基列号、原文和 bbox）。`label_cell` 保存两段原文以换行连接，`table_row` 为第一段所在行。金额零基列号仍为原物理列 4、5。

## 实际运行与限制

`backend/tests/test_annual_statement_probe.py` 实际 **76 项通过，5.21 秒**，未跳过原 PDF 回归；Ruff 检查通过。相对原 54 项增加 21 个手写机制测试及 1 个真实原文回归。包括归母/小计/合并总计、非相邻行、不同列或 x 范围、间隔或重叠、金额未跨完整高度、额外文字或单元格、真实缺金额、片段不在自身原文范围等拒绝路径。原有三个真实样例的期望值没有改写。

新全量运行保存在忽略目录 `.local/annual-statement-probe/all-local-split-v4.json`，结果 **30 个尝试、23 个 observed、7 个 rejected**；2023 为 7/3，2024 和 2025 各为 8/2。永辉 2023 是唯一新观察；其余 7 个拒绝仍是红旗连锁/广联达各三年缺明确货币上下文，以及苏宁 2023 组合报表标题未支持。旧 `all-local-v1/v2/v3.json` 保留。
