## 当前支持范围

- 同一页上近似水平、单行单元格的表格。表头必须同时有“日期/业务日期”“金额/业务金额”以及至少一个其他支持字段，每列须明确且不重叠。
- 其他支持表头：编号/来源编号/流水号、摘要/说明、交易对手/往来单位、订单号、发票号、参考编号。未知列、重复映射或重叠表头明确保留为未归类，不猜测其含义。
- 按文字框的垂直中心和高度形成有界行分组，避免相邻行通过连续重叠合并。按表头中心的中点划分列；整段文字必须落在一列内。跨列或同单元格多个观察时，该行不可自动加入草稿，原观察保留可回查。
- 日期只规范化有效的 `YYYY-MM-DD` 或 `YYYY/MM/DD`；金额只接受明确的整数、至多两位小数及合法千分位格式，用Decimal输出字符串。`0`保留为`0.00`；缺失不补零，`1O0.00`、不合法分组、科学计数法、三位小数和货币符号均保留问题，不替换字符或四舍五入。
- 正确定位但缺少可解析日期/金额的行，可加入草稿后人工补齐。无法确定行列归属的行不能自动复制。合计、备注等表尾及表外文字按原因单独列出，不能无声丢弃。
- 每页最多2000个观察、100个数据行候选。超限显示未完整完成和剩余未归类观察。失败页显示失败，空白页或不支持的结构显示未找到候选。

这是固定规则的几何提取，不是训练好的通用表格结构模型。没有识别表格线或合并单元格；复杂旋转、多行单元格、跨页连续表、无明确表头、收入/支出双金额列、会计借贷列等均不在本次支持范围。低置信OCR仍可能识别出语法合法的错误值，几何和格式校验无法证明业务事实。

## 网页流程和来源边界

在“数据接入 → 扫描件人工核实”中选择已完成任务，点击“识别本页表格候选”。点击表头或单元格回查原文框；未归类文字也可逐段定位。选择行并**人工选择业务类型**后，点击加入人工草稿。候选不会预选、不会自动赋予制度/期间/类型，也不会跳过整批人工确认。

加入草稿保留字段观察ID，沿用原文件哈希、任务结果哈希、页码和多边形定位。只替换初始空草稿，其余未保存草稿保留；超过100条时明确拒绝。修改草稿撤销确认；保存复核和确认导入分别执行既有全部校验。原OCR始终为 `unconfirmed`。

接口为 `GET /api/v1/ocr/runs/{id}/table-candidates?book_id=…&page=…`：先核验账套所有权、任务状态、账套政策版本、原件字节和OCR结果摘要，再运行提取。响应绑定 `run_id/result_digest/page/schema_version`；候选ID还绑定算法版本、表头和该行观察。浏览器拒绝范围不匹配的响应，切换任务或页面后丢弃迟到结果。

没有新增依赖、迁移、会计规则或运行Agent工具。源码见 `backend/app/ocr_tables.py`、`frontend/src/components/OcrTableCandidates.vue`。

## 独立样本与验证

`datasets/generate_ocr_tables.py` 用手写数据生成两张明确标为教学合成的印刷图，并在独立truth目录保存预期。使用本机已安装中文字体，不分发字体。OCR命令仅接收图像及既有模型目录，运行时不读取truth，也不使用提取程序生成预期答案。

明确四列表格包含三行：

|日期|编号|摘要|印刷金额|人工预期金额字符串|
|---|---|---|---|---|
|2026-09-03|T101|办公采购|1,250.50|1250.50|
|2026-09-10|T102|预付订金|0.00|0.00|
|2026-09-21|T103|设备维修|2,040.07|2040.07|

本地固定PP-OCRv5检测/识别模型实际输出18段观察，候选三行的12个字段与手写预期一致，标题和备注另列未归类。第二张使用“收入/支出”表头的结构负对照输出 `no_table`，没有编造金额列。两个样本很小且版式简单，不构成真实票据准确率或通用表格识别能力证明。

新增22项专项检查覆盖日期/金额歧义、真实零与缺失、未知列、重复表头、跨列、多观察单元格、表尾、预算、失败页、来源身份及只读API。真实浏览器完成候选回查、无预选、人工类型、加入三条草稿、复核后导入和零值保留；负对照不生成预览或记录。最新测试、原始响应和源码哈希见 [ocr-table-validation.json](ocr-table-validation.json)。

```powershell

.venv/Scripts/python.exe -m pytest backend/tests/test_ocr_tables.py -q
cd frontend
# 当前浏览器验收固定使用已保留的 .local/ocr-tables-v1 样本。
$env:OCR_TABLE_TESTS='1'
npm run test:e2e -- tests/ocr-tables.spec.ts
```
