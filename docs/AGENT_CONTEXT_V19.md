# v19 按需读取快照证据：实现与验证边界

当前源码为 `investigation-v19` / `snapshot-tools-v9`。v18 的固定多 Agent 仍有预算失败，产品试跑最终因 HTTP 402 终止；[原报告](AGENT_PILOT_V18.md)保留失败和未执行任务。v19 尚无真实模型验收，不宣称节省费用、提高准确率或完成多 Agent 闭环。

## 实际变化

旧模型视图在每次新对话中重发累计查询结果、完整记录及政策全文。v19 保留完整持久记忆，模型每个角色从自己的读取集合重建视图。初始集合为空；主动选择器明确交接的那个查询仍随交接提供完整结果。

- `query_manifest` 列出全部既有查询的参数、结果字段、匹配/截断/是否检索等元数据，以及可读内容哈希。`payload_in_view=false` 表示当前角色未读全文，不表示没有资料。
- `read_evidence_queries(query_ids)` 每次最多读取 6 个已有查询，只访问本运行固定快照的记忆。重新调用原具名查询也能读取已有缓存。完整记录、规则定义和政策原文按本角色实际读取集合进入上下文。
- 请求补证和 `verify_claims` 的 `program_observations` 仍累计全量传递，包括 `false`、`null`、`not_requested`、尚未到达及需要新快照。没有用摘要或“多数同意”覆盖负向结果。
- 专家仍接收最近意见和完整历史索引，最终汇总仍接收全部早期完整意见。历史意见明确为 `model_opinion`，读取它不授予原始证据已读标记。
- 本角色第一次读取全局已有缓存可以继续下一批工具调用；再次读取同一内容不算进展。全局缓存命中、取得新资料、首次呈现给某个角色和业务确认是不同状态。

同一模型和工具权限对四组一致应用，每案 24 次模型尝试、60 次工具、200000 Token，以及每角色两批工具的限制保持不变。没有降低请求大小保护、增加预算、开放任意执行或删除失败。

## 程序约束

记忆绑定记录、账套政策、快照截止、案件、消融状态及执行规则内容的指纹。跨账套、新快照、政策/资料变化或无绑定的非空缓存不能重新挂载；旧检查点也不能按新提示词版本继续。哈希用于内容一致性，不是业务正确性或全面防篡改证明。

查询内容哈希包含查询参数与完整结果，以及该结果引用的完整记录和政策片段。它不是只对 ID 列表做哈希。规则定义在所选视图内重新建立一致映射，编码前过滤，编码后的池/表引用不被裁剪。

读取批次包含一个不存在的 ID 时，整个批次拒绝，不部分授予已读状态、不执行新查询、不生成空缓存。所有查询返回和视图均为深拷贝；同一证据身份出现不同内容时原子拒绝，不能将旧金额借给新查询。

运行时结构校验还检查：`finding`/`normal` 断言、`supported`/`refuted` 假说必须引用当前角色真正读到的证据，或初始明确提供的确定性计算依据；政策引用必须先读到全文。索引和其他模型意见不满足这一条件。未读依据可以保留为 `insufficient`/`unresolved`，格式修复不能假称取得新证据。

已读且引用合法仍不证明文字结论正确。模型建议继续保存为 `model_proposal`，核验标明 `semantic_status=unverified_model_proposal`；新增 `evidence_content_read` / `policy_content_read` 只说明输入可见性。

## 独立离线回归

`backend/tests/test_lazy_evidence.py` 当前 39 项通过，使用手写的金额、日期、文档、单位和错误计算，不读取凭证生成器真值或 API 密钥。涵盖：

- 全量内部记忆与所选视图无损往返；截断、无匹配、未检索全文的差别。
- 六项读取、无效/重复/越界批次拒绝和跨范围拒绝。
- 首次与重复缓存读取的进展控制，以及 24/60/200000 预算不变。
- 初次及缓存响应深拷贝、证据身份冲突、原件不改写。
- 中性复核中索引引用被拒绝；读取原文后建议仍不升级为程序事实。
- 完整历史交接、失败计算与未到补证保留；模型意见读取不成为原始证据读取。

v18 的历史交接测试已增加实际原文查询，再核验同一早期发现和冲突；金额答案和事实边界没有改动。只检查“已读”是输入与权限约束，无法证明模型真正理解了原文。

## 可复现字节测量

执行 `python -m benchmarks.evidence_context_probe`，使用 96 条明确标记合成的记录、5 个既有查询、10 个按原查询截断返回的政策片段和一个未到补证。没有运行 Agent 或调用模型，测量只包住 `shared_evidence`，不含系统协议、工具 schema 和意见历史。

| 视图 | 序列化字节 | 完整记录 | 查询载荷 | 索引项 | 政策全文 |
|---|---:|---:|---:|---:|---:|
| 完整内部视图 | 109598 | 96 | 5 | 0 | 10 |
| 角色仅看索引 | 5935 | 0 | 0 | 5 | 0 |
| 角色读一张凭证 | 8477 | 2 | 1 | 5 | 0 |
| 角色读全部查询 | 113370 | 96 | 5 | 5 | 10 |

读全部时索引还会增加传输开销；这不是普遍压缩，也不能据这些字节推算真实 Token 或费用。全部内容仍可读，累计核验过大时预算仍会明确停止。完整多 Agent 是否能够在相同预算内完成、角色如何选出必要原文、是否引入漏检，需要余额恢复后的真实重复实验验证。

结果保存在忽略的 `.local/reports/evidence-context-v19-repro.json`，绑定实际源码哈希。输出已存在时拒绝覆盖；复跑使用新的 `--output` 名称。原 v17/v18 报告没有被改写为新版本成绩。
