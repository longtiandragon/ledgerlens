# 目标文档

更新：2026-10-14。本文把原始规划的目标、验收门槛与当前证据放在一起，供决定下一步做什么时使用。逐项验证细节见 [STATUS](STATUS.md)，接手说明见 [HANDOFF](HANDOFF.md)。

## 1. 最终目标

建设一个能读取账务资料、发现异常、主动查证、模拟处理影响并形成可追溯复核底稿的平台。首版成功的判定：**别人能在本地复现数据、运行调查、检查每条证据、验证计算，并看到多智能体相对基线的真实效果**——包括效果为负时如实呈现。

首版边界：原始账簿只读；调整只进入模拟区；不做正式记账、付款或税务申报；不宣称覆盖全部准则、替代会计或已证明真实企业节约工时。在没有授权真实账套与专业复核前，定位是**会计复核研究与辅助平台**。

## 5. 决策原则

- 先离线证明机制和数据能区分方法，再花钱测模型；数据集若让确定性基线接近满分，就先改数据而不是跑模型。
- 每个付费实验事先报预算与上限，低谷时段运行，用费用守护包裹，结果（含失败）全部入档。
- 用过的评测划分不再用于调参；结论只在冻结配置和未见数据上给出。
- 负面结果与正面结果同等对待：写入 STATUS、评测中心和本文件。
